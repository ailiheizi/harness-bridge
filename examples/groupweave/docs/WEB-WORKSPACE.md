## 使用变化

- **工作台**：当前群/角色/规则版本可见；常用入口指向工具目录、功能配置、规则历史。
- **工具目录**：文件、音视频、图片/PDF、Markdown、公开解析、RSS、提醒七组说明；
  可按类别/关键词搜索、展开步骤、复制命令。在 Telegram 使用，不在目录执行。
- **功能配置**：文本/AI 能力与六类 Telegram 原生工具开关分区。旧 reminder 占位
  不再出现在应用能力列表中；实际提醒属于原生 schedule 工具。
- **插件管理**：平台先区分原生插件/依赖和群可选应用能力；原生维护再分已安装、
  安装/升级、配置。真实状态仍来自原 Installer/Loader API，平台配置 JSON 留给维护者。
  本地合成预览不提供插件安装，未读到真实状态时不开放保存。
- **任务与对话**：模型/上下文设置与记录分开；本人运行任务/临时文件可展开，
  历史按功能、编号、可见输入和状态筛选，详情是可键盘操作的按钮。
- **手机布局**：侧栏可开关、菜单选择后收起；工具单列、搜索换行、表单可触控；
  字号/对比度提高，增加跳过导航和 reduced-motion 支持。

“群已允许”只说明群开关，**不等于平台服务已部署**。此目录不伪造部署状态，
也不把本地预览称为 Telegram 功能收件。目录用法的运行条件以
[功能速查](FEATURE-CATALOG.md)和命令提示为准。
