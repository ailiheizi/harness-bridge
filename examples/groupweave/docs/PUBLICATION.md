# Public copy and evidence boundary

This directory is a portable example of the GroupWeave application. The source
and configuration in this copy do not include a deployment's Telegram token,
operator IDs, bot username, host name, environment files, database, or runtime
artifacts. Replace the documented sample values with credentials and IDs from
your own secret store and deployment before enabling live integrations.

Acceptance documents retain historical scope and outcomes as notes. They are
not a live deployment status page, a sample `.env`, a source of user/group
configuration, or a substitute for the current deployment's own verification.
Private receipts, screenshots, logs, fingerprints, hostnames, and local machine
paths were intentionally omitted or generalized in this public copy. Synthetic
fixtures and acceptance-only settings describe those test runs; they are not
production defaults or authorization to use the original operator's account.

The original antiad scoring modules have no verified public redistribution
license and are omitted from this snapshot. The adapter remains optional and
requires operator-supplied, reviewed compatible modules and a read-only model;
the public case does not claim to include the legacy classifier. No attribution
or license has been invented for the omitted code. See
[`integrations/antiad/README.md`](../integrations/antiad/README.md).

Links to private acceptance material were removed. Remaining references to
Harness Bridge documentation point to the repository's `docs/` directory and
should be checked against the final repository layout.
