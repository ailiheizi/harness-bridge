# 本地关键词复核

原生 `/keywords <明确提交的文本>` 与 Web「在线使用 → 关键词复核」调用同一固定代码能力
`antiad`。不发送给模型、不运行训练分类器、不读取聊天历史，也不自动删帖或处罚。
原生宿主和默认预览已内置实现，无新依赖或额外容器。

平台先开放「关键词复核」，群管理员再在「功能配置」启用本群功能。每群独立词表，
每行一项，最多50项、每项80字符；预览确认后生效，可通过原有规则历史回滚。
未配置时使用可见的5个默认词：加群领福利、稳赚不赔、免费领取、兼职刷单、代开发票。
显式空列表表示不做判定，不能与默认词表混淆。回滚恢复原快照的缺省语义。

输入最多8192字节。采用NFKC、大小写、空白与零宽字符规范化后匹配，输出实际命中词；
未命中不代表安全。规则是简单子串匹配，无法识别全部广告或诈骗，不输出概率分数。
旧概率阈值不适用于该后端，面板不显示这些控件。

命令固定返回当前已授权群；Web可选择本人私人结果或本群受众，仍使用当前群的规则。
每次复核都走现有权限、任务重复保护与投递记录，`modelCalls=0`。当前不开放独立私聊入口。

`/scan <文本>` 是另外的显式AI复核，会先确认第三方处理并记录实际模型调用。
可选旧Python分类器需要平台自行提供已审核实现和模型；关键词能力不使其自动可用，
不会把规则结果称为分类器分数，也不加载旧训练数据库。

本轮验证仅覆盖新增接缝：默认词/空词、逐群词表、取消与非法scope；宿主实际实现标记与
私人结果；清空预览及回滚；原生命令的重放、错误Bot目标与停用。没有重测上游生态。

已部署到当前原生Bot，平台开关仍保持关闭，未替所有群启用。真实AI复核与订阅摘要的收件
另见[本轮交付](RSS-REVIEW-DELIVERY-20261031.md)；不把其它入口的收件冒称本命令逐群实测。
