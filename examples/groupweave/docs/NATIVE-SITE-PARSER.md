# 可选站点解析

原生 Bot 提供 `/parse <链接>`（中文别名 `链接解析`），也可引用当前会话的一条
链接后发送 `/parse`。当前交付范围仅为匿名、公开可访问的单条视频；不使用 Cookie、
账号登录态、代理或第三方付费解析 API，不探测账号内容。公开视频在上游拒绝、
失效或地区不可用时直接返回失败；这种失败不阻塞当前交付，也不通过重试或登录绕过。

2026-10-27 本机固定 `yt-dlp 2026.10.26` 无 Cookie 提取 B 站官方测试链接
`BV1GJ411x7h7`，生成 6,122,387 字节 MP4。deployment host 对该样例返回可能已删除或
地区受限；另外两个公开 B 站样例返回 `Unable to extract initial state`。远端真实
解析和 Telegram 媒体收件均未通过，不能据本机成功推断部署可用。抖音官方测试样例
要求 Cookie；按当前匿名范围停止，不提供登录态支持。以上已知失败不作为继续探测
其他账号或受限内容的理由。

## 运行边界

通过 `ENABLE_SITE_PARSER=1` 显式启用。平台镜像须安装并固定维护 `yt-dlp`，并提供
FFmpeg 以合并 B 站常见的分离音视频流；可用 `SITE_PARSER_YTDLP_PATH` 指定可执行
文件（默认 `yt-dlp`）。当前交付和部署不配置或导入 Cookie/登录态，也不读取浏览器
配置或系统登录态。代码保留显式 `BILIBILI_COOKIES_FILE`、`DOUYIN_COOKIES_FILE`
兼容分支；该分支不属于当前交付，未配置、未使用、未测试。

直连默认选取不高于 480p、预估视频流不高于 8 MiB 且音频流不高于 2 MiB 的格式，
并以 FFmpeg 合并；最终单个 MP4 不超过 10 MiB，下载与合并临时文件总量不超过约
20 MiB。没有匹配格式或超出限额时会失败，不会裁切视频来适配限制。

旧的受控 API 接缝仅供显式配置的兼容部署：

```text
SITE_PARSER_API_URL=https://your-approved-provider.example/parse
SITE_PARSER_API_KEY=（私有密钥）
```

仅当 URL 和密钥都配置时使用该 API；只配置一项会报配置不完整。服务需兼容
`koishi-plugin-video-parser-all@1.7.7` 支持的 GET `url` 参数、`X-API-Key` 请求头
和媒体字段。当前运行验收不依赖此 API；没有隐式备用端点或自动切换。

命令每次处理一个支持的 HTTPS 链接，不自动监听群聊天。媒体使用普通 Telegram
图片/视频上传；每个媒体最多 10 MiB、总计 20 MiB。解析失败、失效链接、格式不支持
和媒体投递未知均明确提示不完整。每人当前会话一项、全局两项，忙时不排队；单次
任务最长 60 秒。没有 `/cancel` 命令；宿主关闭时会终止活动的 yt-dlp 进程并清理
临时目录。投递前重新核验授权。

手动入口和本地提取证据不等于目标部署功能通过。当前不要求登录内容、逐群自动解析
开关或所有站点成功；不支持私密、会员、登录限定内容、批量抓取、大视频或下载重试。

参考：[上游说明与源码](https://github.com/Minecraft-1314/koishi-plugin-video-parser-all)。
